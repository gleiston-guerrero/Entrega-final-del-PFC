# Entrega 4 — snapshot histórico

`Informe_E4_SCLI_FUVV.pdf` es el único artefacto histórico de la Entrega 4
conservado en esta carpeta, acompañado por este README explicativo.
La carpeta no contiene fuentes vigentes.

El PDF fue generado antes de las últimas integraciones documentales de E3/E4 y
antes de la incorporación de los contratos OpenAPI de E5. No debe interpretarse
como representación del HEAD documental actual.

La única fuente oficial actual es [`../main.tex`](../main.tex), compilada por
GitHub Actions como `docs/main.pdf` y publicada como artifact.
Las fuentes modulares actuales están en [`../secciones/`](../secciones/).
